# Security and privacy policy

ClinDrift is a research prototype handling clinical-text examples. Security and privacy reports are welcome.

## Do not disclose publicly

Please do not open a public issue containing:

- identifiable patient information;
- private clinical records;
- credentials, API keys, or tokens;
- exploit details that would create immediate risk for a deployed environment;
- employer/client confidential data.

## Reporting

For security-sensitive findings, contact the maintainer privately through an established professional contact channel before public disclosure. Provide:

- affected version or commit;
- reproducible steps using synthetic/de-identified data;
- expected versus observed behaviour;
- security/privacy impact;
- suggested mitigation if known.

## Scope

ClinDrift is not a medical device and is not intended for clinical decision-making. Reports about clinical correctness should distinguish software defects from broader clinical-validation questions.
